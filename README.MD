# Kepegawaianku App

Aplikasi kepegawaianku app berbasis website yang tujuannya adalah mengelola data pegawai non asn

## Features

- CRUD Employee Data
- CRUD Employee Documents
- CRUD Departments
- CRUD Positions
- CRUD Leave Types
- Manage Employee Leave Balances
- Manage Leave Requests
- Dashboard for employee information overview

## Tech Stack

- Express.js
- React.js
- TypeScript
- Tailwind CSS
- MySQL

## Installation

1. Clone Repository

```
git clone https://github.com/Nandaakbar15/kepegawaian-app.git
```

Masuk ke folder project:

```
cd kepegawaian-app
```

2. Backend Setup

Masuk ke folder backend:

```
cd kepegawaian-backend
```

Install dependencies:

```
npm install
```

Jalankan backend:

```
npm run dev
```

atau jika menggunakan nodemon:

```
nodemon app.js
```

<br>

3. Frontend Setup

Buka terminal baru dan masuk ke folder frontend:

```
cd kepegawaian-frontend
```

Install dependencies:

```
npm install
```

Jalankan aplikasi:

```
npm run dev
```
